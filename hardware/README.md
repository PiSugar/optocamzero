# Original Optocam Zero Hardware (Upstream)

> **Important:** This directory is inherited from the upstream original
> Optocam Zero project. Its BOM, build guide, Bambu Studio projects, STL files,
> and CAD model do **not** describe the Whisplay HAT + PiSugar 3 Air version.
> For the current Whisplay enclosure, use the
> [PiSugar 3 Air + Whisplay Optocam case files](https://github.com/PiSugar/suit-cases/tree/main/pisugar3air-whisplay-optocam).

Everything you need to build an Optocam Zero, the 3D print files, required parts list, and detailed step by step build guide can be found in this hardware folder.

If you're considering building one, check the BOM to get an idea of the cost for required tools and parts. Also, have a look at the build guide, it will give you a clear idea of what the build involves.

## 3D Printing the Parts

All parts in this original design are recommended to be printed with PETG for heat resistance. PLA parts may deform under heat generated by the electronics.

The parts are tested with PETG, transparent PETG and PETG-CF.

If you're using a Bambu Lab printer for the original design, ready-to-print Bambu Studio files are provided for transparent PETG and PETG/PETG-CF. If you're printing transparent PETG, make sure the filament is well dried beforehand for maximum transparency.

All front and back pieces print flat on the plate, so the build-plate texture will be carried over to the camera surfaces. A smooth plate is recommended for maximum transparency; textured plates create a frosted finish.

Two color 3D printing is only needed for the front cover logo and the two colored front spacer. If you don't want to have these, you can print all the pieces single color.

The optional case is printed with TPU. If you haven't printed with TPU before, check general TPU printing instructions.

**IMPORTANT:** The front spacer part that goes on top of the screen module has 2 versions with different thicknesses. This is because the LCD module on the display HAT may vary in thickness between batches. Test both front spacers and use the one that fits flush to the display HAT. Assembling the camera with the wrong front spacer part can damage the LCD.

## Before You Start

Make sure you have all the required parts, tools and 3D printed components ready before you begin.

Read through all the steps in the build guide before starting. Some steps have a specific order that can't be reversed easily.

This build requires basic soldering and desoldering. If you haven't soldered before, it's worth practicing on some scrap components first.

Take your time, especially with the ribbon cable (order extras to be safe) and the header pin soldering/desoldering. These are the most delicate parts of the build and mistakes here are difficult to undo. Be patient with it.
